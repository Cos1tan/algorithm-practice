算法与程序设计练习记录。目的是把编程基础打扎实，不是收集题解。

## 目录

```
luogu/      洛谷题解，按题号命名
leetcode/   LeetCode 题解，按题号命名
notes/      错题、模板、易忘的语法
```

文件命名：`题号_题目名.扩展名`，例如 `luogu/P1001_A+B_Problem.c`。

## 节奏

- 每天至少 1 题，无论多简单。连续性比难度重要。
- 每题都写解，但不一定写最优解——先做出来，再回头优化。
- 卡超过 30 分钟就看题解，然后**合上题解自己重写一遍**，在 `notes/` 里记下卡在哪一步。
- 每个文件头部写清楚：题目来源、链接、日期。

## 语言

以 C 为主，Python 用来快速验证思路。
